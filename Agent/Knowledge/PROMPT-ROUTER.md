# Prompt Router

> Gunakan daftar routing di bawah ini untuk menentukan file _Workflow_ yang wajib dibaca saat user mengirim prompt minimal.

## Routing

Jika user memberikan flag **BUG:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-bug-fix.md`

Jika user memberikan flag **ENHANCEMENT:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-enhancement.md`

Jika user memberikan flag **NEW PAGE:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-new-page.md`

Jika user memberikan flag **AUDIT:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-audit-standardization.md`

Jika user memberikan flag **E2E TEST:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-e2e-selenium.md`

Jika user memberikan flag **INTEGRATION VERIFY:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-integration-verification.md`

Jika user memberikan flag **ANALYZE:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-reverse-engineering.md`

Jika user memberikan flag **CONTRACT GENERATE:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-contract-generator.md`

Jika user memberikan flag **RELEASE REVIEW:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-release-review.md`

Jika user memberikan flag **TEST:** atau **TEST MODULE:** atau **TEST REGRESSION:** atau **TEST BUG:**
→ Buka dan ikuti: `Agent/Knowledge/Workflows/workflow-ui-testing.md`
