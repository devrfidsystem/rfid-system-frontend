# Knowledge Master Index

## Source Of Truth Matrix

Repositori Knowledge ini diatur dengan prinsip _Single Source of Truth_ (Satu Kebenaran). Modifikasi, penulisan aturan, atau pencarian informasi wajib merujuk ke folder utama (owner) masing-masing topik.

- **Business Rules** → `Domains/`
- **API Contract** → `Contracts/`
- **API Implementation** → `API/`
- **UI Standard** → `UI/`
- **Screen Documentation** → `Screens/`
- **Component Documentation** → `Components/`
- **Wiring Documentation** → `Wiring/`
- **Testing Documentation** → `Testing/`
- **Automation Documentation** → `Automation/`
- **Architecture Documentation** → `Architecture/`
- **Security Documentation** → `Security/`
- **Workflow Documentation** → `Workflows/`
- **Release Documentation** → `Release/`
- **Decisions** → `Decisions/`

Setiap dokumen di dalam folder ini memegang kepemilikan tunggal (Single Ownership) atas ranah informasinya. Agen tidak diizinkan untuk menduplikasi ketentuan dari satu folder ke folder lainnya.
