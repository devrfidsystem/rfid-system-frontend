# Warehouse Notes Alignment Design

## Goal

Align Putaway, Opname, Relocation, Outbound, document numbering, and location handling with the approved warehouse workflow.

## Decisions

- Opname `Adjust` changes counted quantity; Opname `Relocation` creates a real relocation transaction after destination selection.
- Opname submits one location at a time and reconciles only after all selected locations are submitted.
- Outbound mobile has no visible `In progress` business status; leaving the page discards temporary scan state and reopening requires location scanning.
- Transfer is removed from user-facing web flow; Relocation handles same-warehouse and cross-warehouse movements.
- Document numbers are generated by document type (`INB`, `PUT`, `OUT`, `REL`, `OPN`) and are not user-entered in operational forms.
- Foreign outbound EPCs resolve to product names; unregistered EPCs block submission.
- Locations without EPC tags remain selectable manually.

## Architecture

Backend remains the source of truth for stock mutations and document lifecycle. Web and mobile clients submit explicit DTOs and keep scan progress local. Existing service/API boundaries and colocated unit tests are preserved.
